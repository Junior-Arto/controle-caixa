# Controle de Caixa

App estático (HTML + CSS + JS, sem build) para visualizar lançamentos de extrato bancário:
saldo atual, totais de crédito/débito, busca por texto e filtro por tipo (crédito, débito, saldo dia, juros/correção).

> ⚠️ Os dados no `index.html` são **ilustrativos/fictícios** (nomes e conta mascarados).
> Para usar com dados reais, edite a constante `lancamentos` e o bloco do cabeçalho — não commitar dados reais aqui.

## Rodar localmente

Abra `index.html` no navegador, ou:

```bash
python3 -m http.server 8000
```
